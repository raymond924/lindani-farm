One file per page. Each file is a single block of code for one GoHighLevel (GHL) page.
Styles, scripts, photos and fonts load from https://lindanifarms.netlify.app/, so keep
that Netlify site running: it is what keeps every page up to date.

The paths must match exactly: the menu and footer link to `/studios`, `/farm` and so on.
Page descriptions for GHL's SEO settings are in `pages.tsv`.

## For each page

1. Sites > Websites > your Lindani website > Add page. Name it, and set the path from the table.
2. Open the page in the builder. Delete everything on it (header, footer, default sections).
3. Add one Section. In its settings: Full width, padding 0 on all sides, no background.
4. Add one Row (1 column) in it, also with padding 0, then add the element "Custom JS/HTML" (Code).
5. Open the file below, copy all of it, paste it into the element, and save.
6. Page settings (gear) > SEO: paste the title and description.
7. Save and publish. The editor preview may look blank or unstyled: the code runs on the
   published page, so always check the live URL.
